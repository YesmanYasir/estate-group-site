# Property listings workflow

1. Read `AGENTS.md`, `docs/property-editor.md`, `studio/schemas/property.ts`, and the public query in `site/js/data.js`.
2. Keep field names and types aligned across Studio schema, frontend mapping, and documentation.
3. Do not invent sale facts. Use clearly marked illustrative fixtures only when a sample is required.
4. Public queries must return published records only; never query drafts or expose write credentials.
5. Keep empty, loading, and fetch-error states clear and usable.
6. Ensure image alt text, currency formatting, area units, and status display are accessible and accurate.
7. Summarize schema/data changes and list any owner-supplied content still needed.
