# Visual review

Read `QUALITY_CHECKLIST.md` and the Better React Web UI `frontend-design` skill's visual verification reference. Run the site and inspect real browser screenshots at wide desktop and narrow phone widths. Review first impression, hierarchy, density, imagery, clipping, interactions, focus, reduced motion, and empty/error states. Fix only issues in scope. Report what was actually observed; do not infer browser or performance results from source alone.
