# Creative direction

Read `CREATIVE_DIRECTION.md` and `DESIGN.md`; inspect the current experience. State the visitor task and visual thesis, then derive a consistent palette, typography, image approach, composition, and motion. Preserve truthful content and accessibility. Avoid generic luxury tropes and decorative 3D without user value. Deliver a concise rationale and clear handoff.
