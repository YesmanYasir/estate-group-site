# Pre-launch review

Review desktop and mobile layouts, keyboard operation, accessible labels and contrast, metadata, canonical host, responsive image sizes, link/form behavior, missing pages, empty/error states, privacy notice, and contact details. Check that all demo listings and preview disclaimers are replaced before publication. Confirm Sanity project IDs, public dataset policy, Studio sign-in, and no write token or secret is present in public files. Report findings by severity; do not silently fabricate factual content or legal terms.
