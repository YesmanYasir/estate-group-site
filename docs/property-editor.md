# Property editor quick guide

The editor is Sanity Studio, a browser-based content form. No code changes are needed to create, edit, publish, or hide a property.

## Add a property

1. Open the Admin link from the website (once `studioUrl` is configured).
2. Sign in using an invited Sanity editor account.
3. Choose **Properties → Create**.
4. Enter the approved title, URL slug, listing type, status, price/currency, city, neighborhood, property type, bedrooms, bathrooms, area, short description, full description, and features.
5. Upload a cover photo and supporting gallery. Add descriptive alt text and ensure the business has permission to publish each photo.
6. Mark **Featured** only when the owner wants the listing on the homepage.
7. Preview the entry and click **Publish**.

## Change or remove

Open the property in the Studio, make changes, and publish. To keep a record but remove it from available search, change status to Sold, Rented, or Hidden. Do not delete a listing unless the business has decided it should be removed permanently.

## Fields and safeguards

Prices, floor area, room counts, eligibility notes, and property availability are supplied by the editor. Verify them before publishing. Avoid storing buyer identities, financial information, access codes, or other private information in public property content.
