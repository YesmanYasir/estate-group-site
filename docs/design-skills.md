# Design skills used in this project

The upstream skills are pinned by `skills-lock.json` and restored into `.agents/skills/` with `npm run setup:skills`. Run that command once after cloning; it also enables the Impeccable design hook. Project-specific facts and the visual direction in `AGENTS.md` and `DESIGN.md` take precedence.

| Skill | Upstream | What it contributes here |
| --- | --- | --- |
| `emil-design-eng` | [emilkowalski/skills](https://github.com/emilkowalski/skills) | Animation judgment, precise transitions, component polish, and interaction feedback. |
| `impeccable` | [pbakaus/impeccable](https://github.com/pbakaus/impeccable) | Design vocabulary, layout/typography polish, accessibility and anti-pattern review, and a code detector. |
| `design-taste-frontend` | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) | Art direction, strong content hierarchy, useful photography, responsive design discipline, and browser finish checks. |
| `frontend-design` | [aladicf/better-react-web-ui](https://github.com/aladicf/better-react-web-ui/tree/main/skills/frontend-design) | Project-aware React design and accessibility references, including search and filtering UX. |

The skills and their supporting assets are development-time material; they are not imported into the website bundle. Their upstream licenses remain with the installed skills.

For this update, the search surface adds shareable URL filters, a bounded price range, sorting, removable active-filter chips, and a clear recovery path. Property facts now use consistent bed, bath, and area icons with explicit text labels. The existing editorial photography, typography, and restrained motion remain the design authority.
